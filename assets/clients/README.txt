TIPS:
- Square ya landscape format best lagta hai (ek jesa size)
- PNG transparent background (white ya dark dono pe chale)
- SVG recommend hai — crisp at all sizes
- Recommended size: 120x40px ya 80x80px square

KAISE LAGEIN:
  1. Is folder mein logo file rakho (e.g. hyundai.png)
  2. config.js open karo
  3. us client ki entry mein "logoImage" field update karo:
       { name: "Hyundai", sub: "Gujranwala", logoImage: "assets/clients/hyundai.png" }
  4. File save karo — logo foran dikh jayega!

Agar logoImage blank chhorein to: sirf naam dikh ta hai (no icon).
